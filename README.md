# A Little Place for Your Feelings ♡
### *A Handcrafted Digital Sanctuary & Personal Gift*

> *"Whatever you're feeling today, there's a little place here for you."*

---

## 🌙 About The Project

**A Little Place for Your Feelings ♡** is a thoughtful, interactive website designed as a personal gift. Inspired by Studio Ghibli aesthetics, illustrated storybooks, handwritten letters, and quiet starry nights, it creates a cozy corner of the internet where someone can feel appreciated, comfortable, and free to simply be herself.

---

## ✨ Features

- **🌙 Opening Starlit Gate**: An illustrated night sky with a softly glowing moon and slow cinematic text reveal leading to `[ Come Inside ♡ ]`.
- **🍃 5 Interactive Mood Worlds**:
  - **Happy ☀️ (Golden Afternoon)**: Floating dandelion seeds, butterfly release interaction, uplifting verses, and the happiness jar.
  - **Sad 🌧️ (Cozy Rainy Room)**: Rain on window glass, steaming mug of tea, warm lamp glow, guided breathing exercise, and the letter *"Open When Things Feel Heavy"*.
  - **Tired 🌙 (Midnight Bedroom)**: A breathing moon, bedtime thoughts deck, and a button to dim the interface for restful sleep.
  - **Overthinking ☁️ (Lavender Sky)**: Floating paper cloud thought release, private local journal, and 5-4-3-2-1 sensory grounding.
  - **I Don't Know ♡ (Twilight Lake)**: Liquid water ripples upon clicking, floating affirmations, and unhurried Zen mode.
- **🍯 The Little Happiness Jar**: 35 original folded origami paper notes across poems, gentle reminders, compliments, quiet thoughts, and silly jokes.
- **✉️ A Letter For You**: A vintage paper envelope sealed with a red wax heart that unfolds into a handwritten personal letter.
- **🌸 The Secret Garden**: A hidden nighttime garden tucked behind *"Psst... there's something else"*, with drifting fireflies, moon reflections, and 5 discoverable interactive blooming blossoms.
- **🎵 Procedural Ambient Sound Engine**: Built 100% with the Web Audio API—generates soothing procedural soundscapes (rain, felt piano, meadow breezes, celestial drones, and lake swells) with zero external audio assets.
- **🔒 Privacy First**: Private thoughts and keepsake favorites are stored strictly in local browser storage (`localStorage`).

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Vite**
- **Framer Motion**
- **HTML Canvas** (Atmospheric particles, rain streaks, liquid ripples, and fireflies)
- **Web Audio API** (Procedural ambient audio synthesis)

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js (v18+)** and **npm** installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# Navigate into the project folder
cd happy

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
